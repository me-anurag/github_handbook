GitHub File Types Showcase

Every file format GitHub can render, in one repo.

What is this?

This repository demonstrates how GitHub renders different file types — from Markdown to Jupyter notebooks to interactive maps.

Supported Formats

  • .md — Markdown
  • .csv — Spreadsheet table
  • .svg — Vector image
  • .geojson — Interactive map
  • .ipynb — Jupyter notebook

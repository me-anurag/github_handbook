This is a sample .html file. On GitHub, HTML files are shown as source code — not rendered as a webpage. They render as a live webpage only when served via GitHub Pages.

Why GitHub doesn't render HTML

Rendering arbitrary HTML in the browser would be a cross-site scripting (XSS) security risk. GitHub sanitizes HTML inside Markdown, but shows raw .html files as syntax-highlighted source.

When HTML does render

  • When deployed via GitHub Pages
  • When embedded (sanitized subset) inside .md files

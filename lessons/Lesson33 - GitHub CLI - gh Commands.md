# Lesson 33: GitHub CLI - gh Commands

## What this lesson covers

Doing GitHub things (PRs, issues, repos) from the terminal without touching a browser.

### Intuition to build
- `gh` is the official GitHub CLI - it wraps the GitHub API in human-friendly commands
- Some workflows are faster from the terminal: creating a PR, checking CI status, reviewing issues
- It's not a replacement for the UI - it's an alternative for terminal-first developers

### What to include
- Installing `gh` and authenticating (`gh auth login`)
- `gh repo create`, `gh repo clone`
- `gh pr create`, `gh pr list`, `gh pr view`, `gh pr merge`
- `gh issue create`, `gh issue list`
- `gh run list` - checking Actions runs
- Creating aliases in `gh`

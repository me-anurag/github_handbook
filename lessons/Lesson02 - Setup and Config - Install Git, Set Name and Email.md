# Lesson 02: Setup and Config - Install Git, Set Name and Email

## What this lesson covers

Getting Git installed and telling it who you are.

### Intuition to build
- Git needs to know your identity because every commit is stamped with your name and email
- Global config vs local config - one applies everywhere, one applies per project

### What to include
- Install instructions for Windows, macOS, Linux
- `git config --global user.name` and `user.email`
- `git config --list` to verify
- Choosing a default editor (`core.editor`)
- Quick mention of `--global` vs `--local` flag difference

### What NOT to include
- SSH setup (that's lesson 03)
- Any repo commands yet

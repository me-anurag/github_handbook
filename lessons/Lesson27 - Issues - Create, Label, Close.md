# Lesson 27: Issues - Create, Label, Close

## What this lesson covers

GitHub's built-in system for tracking bugs, features, and tasks.

### Intuition to build
- Issues are the todo list of a project - conversations anchored to a specific problem
- Labels, assignees, and milestones turn a flat list into an organised backlog
- Issues and PRs are deeply linked - a PR can close an issue automatically

### What to include
- Creating an issue (title, description, labels, assignees)
- Built-in labels and creating custom ones
- Milestones - grouping issues by goal or version
- Closing an issue via a PR (`Closes #N` in commit/PR body)
- Issue templates - consistent reporting structure
- Searching and filtering issues

# Lesson 15: Aliases - Shortcuts for Long Commands

## What this lesson covers

Making Git faster to use by creating your own command shortcuts.

### Intuition to build
- You type the same long commands dozens of times a day - aliases eliminate that
- Aliases live in your `.gitconfig` and are completely personal

### What to include
- `git config --global alias.st status`
- A set of useful aliases: `co` for checkout, `lg` for a pretty log, `undo` for soft reset
- The `lg` alias in full (the one-liner that shows a beautiful graph)
- Where aliases are stored in `.gitconfig`
- Difference between Git aliases and shell aliases

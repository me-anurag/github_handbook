# Lesson 04: Creating Your First Repo - git init

## What this lesson covers

Turning a plain folder into a Git-tracked project.

### Intuition to build
- `git init` just creates a hidden `.git` folder - that's the entire database
- A repo is just a folder Git knows about
- The working directory vs the repository (two different things in the same place)

### What to include
- `git init` in a new folder
- What the `.git` folder is (don't open it yet - just know it exists)
- `git status` - the first command to run after init
- Creating a file and seeing it as "untracked"
- Brief mention of `git init` vs cloning (cloning is lesson 23)

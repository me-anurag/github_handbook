# Lesson 29: README and Markdown - Write a Good README

## What this lesson covers

The front door of your project - and the Markdown syntax to make it look great.

### Intuition to build
- A README is the first thing anyone sees - it answers "what is this and how do I use it?"
- Markdown is just plain text with light syntax for formatting
- A good README can make an average project look professional

### What to include
- Markdown syntax: headings, bold, italic, lists, links, images, code blocks, tables
- What a great README includes: title, description, installation, usage, contributing, license
- GitHub-flavored Markdown extras: task lists, emoji, alerts
- Badges (build status, license, version) - what they are and how to add them
- README for a personal profile repo (GitHub's special feature)

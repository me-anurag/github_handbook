# Lesson 32: Collaborating on a Team Repo

## What this lesson covers

Putting all the pieces together - what day-to-day collaboration actually looks like on a shared repo.

### Intuition to build
- Solo Git and team Git feel very different - the main challenge is staying in sync
- A good team workflow minimises conflicts and maximises visibility
- Everything from lessons 16-31 comes together here

### What to include
- Inviting collaborators (Settings -> Collaborators)
- The daily loop: pull before you start, branch, commit, push, open PR
- Handling a diverged branch (`git pull --rebase`)
- Reviewing and merging teammates' PRs
- Communicating through issues and PR comments
- Repo organisation conventions: folder structure, branch naming, commit message standards

# Lesson 36: Common Errors and Troubleshooting

## What this lesson covers

The errors every beginner hits - and exactly how to fix them.

### Intuition to build
- Most Git errors are recoverable - the message just looks scary
- Knowing the 10 most common errors by name means you'll never be stuck for long
- `git status` and `git log` solve most problems before they escalate

### What to include
- Detached HEAD - what it means, how to get back
- "Your branch is ahead/behind origin" - what to do
- Diverged branches - the `git pull` that gives you two options
- Failed push (rejected) - when and how to force push safely (`--force-with-lease`)
- Authentication errors (SSH misconfigured, token expired)
- Accidentally committed to the wrong branch
- `fatal: not a git repository` - and why it happens
- Merge conflict that won't resolve - using `git merge --abort`

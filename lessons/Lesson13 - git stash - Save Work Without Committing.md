# Lesson 13: git stash - Save Work Without Committing

## What this lesson covers

Temporarily shelving work so you can switch context without losing changes.

### Intuition to build
- Stash is like a clipboard for your uncommitted work
- Useful when you need to pull, switch branches, or fix a quick bug mid-task

### What to include
- `git stash` - stash current changes
- `git stash pop` vs `git stash apply`
- `git stash list` - see all stashes
- `git stash push -m "description"` - naming a stash
- `git stash drop` and `git stash clear`
- Stashing untracked files: `--include-untracked`

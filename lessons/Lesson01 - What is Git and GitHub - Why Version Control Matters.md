# Lesson 01: What is Git and GitHub - Why Version Control Matters

## What this lesson covers

The very first question a beginner asks: *why does any of this exist?*

### Intuition to build
- The "save game checkpoint" analogy - what happens when you can't undo?
- The problem with `final_v2_FINAL_real.docx` - version chaos without a system
- Git vs GitHub - one is a tool, the other is a platform. Students mix these up constantly.
- The big picture: local machine <-> GitHub <-> teammates

### What to include
- A simple before/after: working without Git vs with Git
- Visual of the Git + GitHub relationship (local repo -> remote repo)
- One-line definitions: repository, commit, branch
- Why developers consider Git a non-negotiable skill

### Tone
Purely conceptual - no commands yet. Build excitement and context.

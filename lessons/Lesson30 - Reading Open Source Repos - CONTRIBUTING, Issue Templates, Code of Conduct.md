# Lesson 30: Reading Open Source Repos - CONTRIBUTING, Issue Templates, Code of Conduct

## What this lesson covers

How to navigate an unfamiliar repo and contribute without stepping on anyone's toes.

### Intuition to build
- Every open source project has unwritten rules - the good ones write them down
- Reading the contribution guide before opening a PR is the difference between a welcome contribution and a closed one
- Open source etiquette is a real thing and worth learning

### What to include
- CONTRIBUTING.md - what it usually contains and why it exists
- CODE_OF_CONDUCT.md - why projects have them
- Issue templates and PR templates - filling them in properly
- How to find "good first issues" on GitHub
- Reading the commit history and PRs to understand a project's culture
- `git blame` and `git log -- <file>` for understanding why code exists

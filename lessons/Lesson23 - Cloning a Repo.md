# Lesson 23: Cloning a Repo

## What this lesson covers

Getting a full copy of an existing repo onto your machine.

### Intuition to build
- Cloning is not just downloading files - it copies the entire history
- The cloned repo automatically has `origin` set to where it came from

### What to include
- `git clone <url>` - basic clone
- Cloning into a specific folder name
- What happens after clone: `origin` is set, `main` is checked out
- Shallow clone (`--depth 1`) for large repos when you don't need history
- Cloning via SSH vs HTTPS (and why SSH is preferred after lesson 03)

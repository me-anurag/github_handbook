# Lesson 28: Project Boards and Milestones

## What this lesson covers

Organising issues and PRs into a visual workflow - GitHub's project management layer.

### Intuition to build
- Issues are individual tasks; project boards are the map of how they flow from idea to done
- GitHub Projects (v2) is a full kanban/table/roadmap tool built on top of issues and PRs
- Milestones group work by a shared goal or deadline

### What to include
- Creating a GitHub Project (new Projects v2 interface)
- Board view vs table view vs roadmap view
- Adding issues and PRs to a project
- Custom fields (priority, status, size)
- Milestones: create, assign issues, track progress
- How project boards fit into a team's daily workflow

# Lesson 21: Git Workflows - Gitflow, Trunk-Based, Feature Branch

## What this lesson covers

How real teams organise their branching strategy - the missing bridge between knowing Git and working on a team.

### Intuition to build
- Commands are tools; workflows are the strategy for using them
- No single workflow is correct - different teams use different models
- Understanding workflows helps you adapt to any team's conventions quickly

### What to include
- Feature branch workflow - the simplest baseline
- Gitflow - `main`, `develop`, `feature/*`, `release/*`, `hotfix/*` explained
- Trunk-based development - everyone commits to `main`, short-lived branches
- Comparison table: when each workflow fits (small team vs large team, SaaS vs library)
- How workflows connect to PRs, CI, and branch protection rules

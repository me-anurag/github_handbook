# Lesson 34: GitHub Pages - Deploy a Site From a Repo

## What this lesson covers

Publishing a website directly from a GitHub repository for free.

### Intuition to build
- GitHub Pages turns a repo into a web server - no hosting configuration needed
- Great for documentation, portfolios, and project landing pages
- The site updates automatically when you push to the configured branch

### What to include
- Enabling GitHub Pages (Settings -> Pages)
- Deploying from a branch (`main` or `gh-pages`)
- Deploying from a `/docs` folder
- Custom domains - pointing your domain to GitHub Pages
- Using a static site generator (Jekyll is built-in; mention others exist)
- The URL structure: `username.github.io/repo-name`

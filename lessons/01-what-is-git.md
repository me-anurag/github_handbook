# 01 — What is Git & GitHub

## What you will learn
- What Git is and why it exists
- The difference between Git and GitHub
- Key terms: repository, commit, branch

## Explanation
Git is a version control system. It tracks every change you make to your files
so you can go back to any point in time, work on multiple versions at once,
and collaborate with others without overwriting each other's work.

GitHub is a website that hosts your Git repositories online.
Git is the tool. GitHub is the platform.

## Commands
No commands in this lesson — concept only.

## Example
You write code. You save it. Then you break it.
Without Git, you have no way back.
With Git, you run one command and your code is back to how it was.

## Common mistakes
- Thinking Git and GitHub are the same thing — they are not
- Thinking Git is only for teams — it is just as useful working alone

## Summary
Git tracks changes to your files. GitHub stores those changes online.
Every project you build should use Git from day one.
